# OrgÂnicaWeb
Sistema web desenvolvido com o objetivo de apresentar e comercializar cestas de produtos naturais livre de agrotoxicos, oferecendo opções de cestas pequenas, médias e grandes nelas contendo frutas, verduras e legumes. O cliente faz o pedido pelo site,
celular e retira no balcão ou recebe em casa, sem fila no intervalo.

## Funcionalidades
- Cadastro e login de Clientes
- Catálogo com preços
- Montagem e envio de pedidos

## Tecnologias
- PHP 8.2
- MySQL 8
- HTML, CSS e JavaScript
- XAMPP (ambiente local)
- 
## Como rodar
1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `orgânicaweb` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `database/cantinaweb.sql`.
4. Acesse http://localhost/cantinaweb
Passos detalhados em `docs/instalacao.md`.
